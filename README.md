# Protein Sequence Exercise

This project is based on an exercise involving retrieval and processing of the human preproinsulin protein sequence from NCBI.

## Objectives

- Retrieve the human preproinsulin protein sequence.
- Clean the sequence using Python.
- Verify that the sequence contains 110 amino acids.
- Separate the sequence into its different regions.
- Save each sequence to a separate text file.
- Practice Git and GitHub version control.

## Sequence Files

| File | Amino Acids |
|---|---:|
| preproinsulin-seq-clean.txt | 110 |
| lsinsulin-seq-clean.txt | 24 |
| binsulin-seq-clean.txt | 30 |
| cinsulin-seq-clean.txt | 35 |
